🏛️ Resumen Ejecutivo de la Plataforma

Plataforma empresarial de arquitectura Edge-to-Cloud orientada a la orquestación autónoma de flujos de trabajo comerciales. Integra canales de alta concurrencia como WhatsApp (vía Meta Cloud API) con microservicios asíncronos en FastAPI, y conecta agentes de escritorio de alta disponibilidad para la sincronización en caliente de Microsoft Excel y ERPs locales mediante la API COM de Windows, operando bajo un modelo de costos BYOK de margen cero y arquitectura de red de cero intrusión (Zero Inbound Ports).

🌐 Arquitectura de Flujo de Datos (De punta a punta) Flujo Desacoplado

1. Canal Omnicanal

Meta WhatsApp Cloud API recibe mensajes de texto, audios o remitos. Envía un Webhook HTTPS autenticado al backend en menos de 200 ms.

2. Cloud Core & RAG

FastAPI en Render recibe el evento. Transcribe audios con Gemini Flash Multimodal. La IA extrae intención, pero el catálogo y los cálculos matemáticos se ejecutan en Python puro.

3. Cola de Mensajería

La orden se guarda con estado pending en PostgreSQL. Si la computadora del local está apagada, la orden espera segura sin perderse.

4. Agente Local (Bridge)

Sofía Bridge (.exe) en la PC del cliente hace Outbound Polling saliente. Toma la orden y, vía Windows COM, edita la celda en pantalla en vivo frente al usuario y devuelve el ACK.

🔒 1. Seguridad & Redes Cero Puertos

Especificación de Seguridad Perimetral & Aislamiento de Red

  • Técnica: Zero Inbound Ports (Cero puertos entrantes). No se toca el firewall del cliente.
  • Patrón: Modelo Pull (Outbound Polling): el ejecutable local hace consultas salientes HTTPS al servidor central.
  • Cortes de Luz / PC apagada: Cola Persistente: las órdenes quedan en estado pending. Al prender la PC, el Bridge envía un /ping y descarga todo.
🧠 2. IA sin Alucinaciones Arquitectura Híbrida

Especificación de Integridad de Datos & Motor Híbrido

  • Separación Clave: LLM para Lenguaje + Python para Números. El LLM jamás hace sumas, restas ni inventa precios.
  • Fuzzy Matching: Compara productos aproximados (abreviaturas, faltas ortográficas como P.C., autoperf.) calculando distancias semánticas con algoritmos propios.
  • Grounding / RAG: El agente solo responde con base en las directivas comerciales y el catálogo real del negocio.
💰 3. Costos & Escala BYOK Paradigm

Especificación de Viabilidad Económica & Soberanía de Consumo

  • Modelo BYOK: Bring Your Own Key. El cliente conecta su propia API Key de Google Gemini.
  • Costo Marginal $0: Google otorga 1.500 consultas diarias gratis por cuenta de Gmail. Son 45.000 mensajes al mes a costo cero.
  • Transparencia: No hay sobreprecios de tokens ocultos ni dependencia de facturas imprevistas de OpenAI.
🧪 4. Cómo Testeamos 118 Tests Pasando

Especificación de Aseguramiento de Calidad & Resiliencia

  • Pytest (118 Tests): Cubre cálculo de márgenes, validación de esquemas DB, remitos PDF y lógica del Bridge.
  • Dojo de Combate: Simulador contra 4 arquetipos de clientes: El Apurado, El Caótico, El Tramposo (Prompt Injection) y El Estándar.
  • 🛡️ El Centinela: Smoke Testing Post-Deploy en 3 segundos que audita en vivo: PostgreSQL, Webhook Challenge de Meta y latencia del servidor.
🤝 5. Marco Operativo de Despliegue & Onboarding Sprint de 5 a 7 Días

⏱️ Plazos de Entrega

Prueba de Concepto (PoC): 5 a 7 días hábiles funcionando en 1 o 2 sucursales piloto.
