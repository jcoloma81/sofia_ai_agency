Key Architectural Pillars

Built for Production Reliability, Not LLM Slop

Engineered with defensive system design: strict validation, role-based safety gates, and resilient fallbacks.

🎙️

Multimodal Audio Processing

Handles colloquial voice notes with noisy warehouse background sounds. Accurately extracts SKUs, quantities, and units into structured order payloads.

🛡️

Role-Based Safeguards (RBAC)

Warehouse clerks can record missing items and query inventory, but only authenticated business owners can approve, commit, and dispatch purchase orders.

📈

Automatic Price Shift Detection

When a new supplier catalog is forwarded, the system calculates price delta percentages per SKU and alerts the owner of significant cost spikes before delivery.

⚡

Local Sync Daemon Bridge

A lightweight background client that connects local desktop spreadsheets (Excel / POS) to the cloud FastAPI engine via low-latency polling and webhooks.

🤖

Anti-Hallucination Guardrails

Every AI response is constrained by hard database checks. If a product or price does not exist in verified tables, the model requests explicit clarification.

📊

Executive Telemetry & Audit

Centralized metrics, conversation tracing, error logs, and transaction status monitoring via clean dashboard endpoints.

System Dataflow

End-to-End Orchestration Pipeline

Step 01 // Intake
Inbound Webhook
WhatsApp audio note or forwarded catalog PDF ingested via Whapi Cloud webhook into FastAPI.
Step 02 // Extraction
Gemini Multimodal LLM
Audio transcribed & mapped to strictly-typed JSON schemas via Pydantic model validation.
Step 03 // Logic & Rules
Business Engine
Matches SKUs against database, cross-compares supplier margins, and queues confirmation draft.
Step 04 // Execution
Dispatch & Local Sync
Owner approves via 1 tap. Formal purchase order sent to vendor; local Excel ledger updated instantly.
